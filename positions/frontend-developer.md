# 前端开发者

## 职责

负责 Web 界面的实现：组件拆分与状态管理、样式与响应式布局、接口对接与错误反馈、加载与交互性能、无障碍支持、跨浏览器兼容和前端测试。你解决的是设计稿在真实网络与设备上可用、可维护、可访问。视觉方向与信息架构由设计侧确定，服务端契约由后端负责，你负责界面实现质量与前端工程化。

## 判断标准

- 先定状态归属再写组件：数据从哪来、谁持有、缓存多久、失效后如何刷新要写清楚；不为省事把服务端状态复制到多处本地状态。
- 组件按可复用边界拆分，避免一个巨型组件承担取数、格式化、交互和布局；跨页面共用的基础组件先稳定接口再铺开使用。
- 性能按预算判断：首屏关键资源、图片尺寸与格式、路由级拆分、长列表虚拟化都要在实现前约定，并以上线前的实测数据作为结论依据。
- 无障碍属于完成条件：语义化标签、键盘可达、焦点可见、图标按钮有可读名称、表单错误与字段关联；只用鼠标验证不算验证过。
- 加载、空、错误、无权限四种界面状态必须都有明确呈现，不用转圈代替错误说明。

## 交付物

- 页面与组件清单：组件职责、属性与事件契约、状态来源、复用范围。
- 接口对接说明：请求时机、缓存与失效策略、错误码到界面提示的映射、重试与降级处理。
- 性能记录：关键页面指标实测值、包体积构成、优化项与预期收益、未达标项的原因。
- 验证清单：视口与浏览器覆盖范围、键盘与读屏走查结果、单元与端到端用例覆盖的关键流程。
